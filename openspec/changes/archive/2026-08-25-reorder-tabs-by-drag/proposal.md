## Why

サイドパネルのタブは開いた順に固定され、利用者が並べ替える手段が存在しない。作業中に関連するタブが離れた位置に散らばり、目的のタブを探す視線移動と誤クリックが増える。タブ順は `Cmd+1`〜`Cmd+9` の割り当ての根拠でもあるため、順序を利用者が制御できないことは操作全体の予測可能性を下げている。

## What Changes

- サイドパネルのタブセクションで、タブ行をドラッグ＆ドロップして任意の位置へ並べ替えられるようにする
- ドラッグ中は挿入位置を示すインジケータを表示し、ドロップ時のみ順序を確定する（ドラッグ操作でタブ選択・タブ名編集を誤発火させない）
- 並べ替えた順序を `tabs.json` に永続化し、アプリ再起動後も維持する
- タブ順序を変更する IPC 経路（`tabs:reorder`）を新設し、順序の唯一の正である `TabManager` の内部配列を更新する

### Non-goals

- キーボードによる並べ替え（`Alt+↑/↓` 等）は本変更に含めない。必要になった時点で別変更として起票する
- タブのグループ化・ピン留め・アカウント別セクション分割は対象外
- ドラッグ＆ドロップ用の外部ライブラリ導入は行わない

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `console-window-shell`: サイドパネルのタブセクションに「利用者による並べ替え」の要件を追加する。現行仕様はタブを縦型リストとして表示することのみを定めており、順序の変更手段を規定していない
- `tab-persistence`: `tabs.json` の保存項目に順序が含まれ、起動時の復元が保存順を保つことを明示する。現行の「タブ状態の永続化」要件は順序について沈黙している

## Impact

- **主プロセス**: `src/main/TabManager.ts`（順序変更 API の追加）、`src/main/main.ts`（IPC ハンドラ登録）
- **IPC / 型**: `src/shared/types.ts`（`IPC.tabsReorder`）、`src/preload/preload-ui.ts`、`src/renderer/env.d.ts`
- **レンダラー**: `src/renderer/SidePanel.tsx`（タブ行の D&D ハンドラ）、`src/renderer/side-panel.css`（ドラッグ中・挿入位置のスタイル）
- **永続化**: `src/main/PersistenceStore.ts` は配列順をそのまま保存・復元するため変更不要。順序変更時に既存の保存経路を呼ぶ
- **キーボードショートカット**: `Cmd+1`〜`Cmd+9` と `Cmd+Shift+[` / `]` は配列順に依存するため、並べ替え結果に追従する。`keyboard-shortcuts` の要件文言自体は変更しない
- **依存関係**: 追加なし（HTML5 ネイティブ D&D を使用）
