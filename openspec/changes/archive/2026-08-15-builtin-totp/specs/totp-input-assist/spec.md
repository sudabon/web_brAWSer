## ADDED Requirements

### Requirement: TOTP コードの生成と表示

システムは RFC 6238 に基づいてコードを生成し、現在のコードと残り秒数をパネルに表示しなければならない (SHALL)。

#### Scenario: コードの表示

- **WHEN** 解錠済みの状態で TOTP パネルを開く
- **THEN** 登録済みシードごとに現在のコードと、残り秒数を示すリングが表示される

#### Scenario: 期間経過時の更新

- **WHEN** シードの `period`（既定30秒）が経過する
- **THEN** 表示されるコードが自動的に次のコードへ更新される

#### Scenario: 非標準パラメータのシード

- **WHEN** `algorithm` が SHA256 または SHA512、`digits` が8、`period` が30以外のシードが登録されている
- **THEN** そのシードのパラメータに従ってコードが生成される

### Requirement: クリップボードへのコピーと自動クリア

システムはコードのクリックでクリップボードへコピーし、30秒後に自動でクリップボードをクリアしなければならない (SHALL)。

#### Scenario: コピー

- **WHEN** 利用者が表示中のコードをクリックする
- **THEN** そのコードがクリップボードへコピーされ、コピーされた旨が提示される

#### Scenario: 自動クリア

- **WHEN** コピーから30秒が経過し、クリップボードの内容がコピーしたコードのままである
- **THEN** クリップボードがクリアされる

#### Scenario: 他の内容で上書きされた場合

- **WHEN** コピーから30秒以内に利用者が別の内容をコピーする
- **THEN** クリップボードはクリアされず、利用者のコピー内容が保持される

### Requirement: Identity Center サインインページ限定の入力補助

システムは Identity Center のサインインページに限り、MFA 入力欄を検出して「入力する」ボタンをオーバーレイ表示しなければならない (SHALL)。他のページで入力補助を提供してはならない (MUST NOT)。

#### Scenario: 入力補助の提示

- **WHEN** `persist:sso-portal` パーティションで Identity Center サインインページの MFA 入力段階が表示される
- **THEN** MFA 入力欄の近傍に「入力する」ボタンがオーバーレイ表示される

#### Scenario: ワンクリック挿入

- **WHEN** 利用者が「入力する」ボタンをクリックする
- **THEN** 現在のコードが MFA 入力欄に挿入される

#### Scenario: 自動送信の禁止

- **WHEN** コードが入力欄に挿入される
- **THEN** フォームは自動送信されず、送信操作は利用者に委ねられる

#### Scenario: 対象外ページ

- **WHEN** AWS マネジメントコンソールなど Identity Center サインインページ以外を表示している
- **THEN** 入力補助のオーバーレイは表示されず、preload は入力欄の検出を行わない

### Requirement: preload の責務限定

AWS コンテンツ用 preload が `contextBridge` で公開する API は、入力補助と後続 change の色バー注入に必要な最小の IPC チャネルのみでなければならない (MUST)。

#### Scenario: 公開 API の範囲

- **WHEN** preload が公開する API を検査する
- **THEN** MFA 入力補助と色バー注入に必要なチャネル以外は公開されていない

### Requirement: TOTP パネルの起動

システムは TOTP パネルをキーボードショートカットで開閉できなければならない (SHALL)。

#### Scenario: パネルの開閉

- **WHEN** 利用者が `Cmd+Shift+T` を押す
- **THEN** TOTP パネルが開き、既に開いている場合は閉じる
